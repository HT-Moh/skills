# Validate Startup Ideas

Find public customer proof before building.

## What it does

- Finds first-hand reports of a customer problem.
- Scores pain, current action, and spending signals.
- Identifies people and communities for interviews.
- Creates questions and a measurable next test.

## Install

```bash
git clone https://github.com/HT-Moh/skills.git ~/src/skills
ln -s ~/src/skills/research/validate-startup-ideas ~/.claude/skills/validate-startup-ideas
```

Restart Claude Code after linking. Use either this link method or the marketplace plugin, not both.
